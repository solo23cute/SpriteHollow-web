# Art briefs — index

The written art direction for Sprite Hollow, kept next to the sheets and atlases
it describes. The PNGs here are generated by the tools in `tools/`; the briefs
are the source of truth for anatomy, palette and layout.

## Character and species

| Brief | What it covers |
| --- | --- |
| [puffle-brief.md](puffle-brief.md) | The original mascot direction: fluffy leaf-cat anatomy, turnaround, expressions and pose list. |
| [puffle-collection-brief.md](puffle-collection-brief.md) | The full species collection target sheet — every puffle form on one roster. |
| [animal-puffle-reference.md](animal-puffle-reference.md) | The eight-tier Animal Puffle guardian roster, contact sheets, silhouette profiles, and duplicate audit. |
| [puffle-palettes.md](puffle-palettes.md) | Exact colour palettes by rarity, mirrored as data in `src/lumi-palettes.js`. |
| [puffle-elemental-brief.md](puffle-elemental-brief.md) | The 26 elemental variants, their hexes and effect motifs, plus the atlas and lineup they generate. |
| [collection-map.md](collection-map.md) | Status map: which brief lines the procedural generator already draws and which still need painted art. |
